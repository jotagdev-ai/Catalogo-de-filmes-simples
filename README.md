Um projeto pessoal de um site de catálogo de filmes, desenvolvido com **HTML e CSS**.

O objetivo é praticar meus conhecimentos em desenvolvimento web, criando uma página para exibir filmes, capas e pequenas sinopses.

Tecnologias utilizadas
- HTML
- CSS

Sobre o projeto
Este projeto está em desenvolvimento e receberá melhorias ao longo do tempo, com novos recursos, ajustes visuais e aprimoramentos no código.

Objetivo
Praticar e desenvolver minhas habilidades em HTML e CSS, adquirindo experiência na criação de páginas web.

Melhorias futuras:

Adicionar novos filmes ao catálogo.

Melhorar a organização e o visual do site.

Implementar novas funcionalidades.

Aprimorar o código conforme minha evolução.
